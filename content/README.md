# Content packages

This directory contains immutable, checksummed Bible packages generated by the ingestion
pipeline in `packages/content`.

```
packages/{versionId}/{versionCode}/
  manifest.json
  versification.json
  books/{BOOK}.ndjson
```

- Only the KJV is committed. It is public domain in the United States. The source and
  verification details are in [`sources/kjv/PROVENANCE.md`](sources/kjv/PROVENANCE.md).
- Licensed translations (NKJV, NIV, NLT, MSG and the catalog-only versions) are not
  present. Their catalog entries remain disabled and unlicensed; add only files supplied
  under a confirmed publisher licence.
- Never edit a package in place. A text or versification change is a new `versionCode`.
- `manifest.json` records a SHA-256 for every book file and for `versification.json`;
  `package.zip` is assembled from those verified files at publish/download time.
